# Skills

The Skills context defines reusable agent workflows. It exists to make specialised ways of working available consistently across Forge work.

## Language

**Goal**:
A desired outcome, together with the reason or constraint that makes it matter, used to evaluate which decisions achieve it.
_Avoid_: Requirement, decision

**Goal-derived decision**:
A decision the agent settles by evaluating the stated goals and their constraints, with a rationale that names those goals.
_Avoid_: User decision, recommendation

**Goal question**:
A question that requests the goal context needed to settle a particular decision.
_Avoid_: Decision question, implementation question

**Invalidated decision**:
A formerly settled decision whose supporting goal has changed or been contradicted.
